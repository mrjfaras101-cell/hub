## 🎨 التصميم (2026)

الواجهة مبنية على أحدث اتجاهات التصميم المفتوحة المصدر على GitHub:

- **Bento Grid** — تقسيم المحتوى إلى بلاطات مرتّبة بأحجام مختلفة (النمط المعتمد الآن في Apple وGoogle).
- **Glassmorphism مضبوط** — شريط تنقّل زجاجي عند التمرير فقط (`backdrop-filter`)، لا في كل عنصر (تجنّباً لإرهاق الأداء).
- **Dark Mode أولاً** — زر تبديل مظهر (🌙/☀️) يُحفظ اختياره لكل زائر، ويتبع إعداد جهازه تلقائياً أول مرة.
- **Design Tokens** — كل الألوان متغيّرات CSS، لذا تغيير لوحة الألوان من اللوحة يغيّر الموقع كاملاً دون لمس الكود.
- **حركة سبرينغ** — انتقالات بـ `cubic-bezier(.22,1,.36,1)`، مع احترام خيار `prefers-reduced-motion`.

| الحقل | من أين تأخذه | مثال |
|---|---|---|
| **اسم المستخدم (username)** | من رابط حسابك: `github.com/` + الاسم. أو أيقونة صورتك أعلى اليمين ← يظهر أسفل اسمك | `mrjfaras101-cell` |

> ⚠️ **اسم المستخدم ليس اسمك الظاهر (Display name)** الذي تكتبه في إعدادات الملف الشخصي — بل المعرّف اللاتيني الذي يظهر في الرابط، ولا يمكن أن يحتوي مسافات أو حروفاً عربية.

🩺 زر **«فحص الحساب والموقع»** في تبويب النشر يتحقق تلقائياً من: وجود الحساب، واسم المستودع، والفرع، وتشغيل الصفحة، وينبّهك إن كانت لوحة المعلم منشورة.

## 🚀 الإعداد لأول مرة (١٠ دقائق)

### 1) أنشئ مستودعاً عاماً
[github.com/new](https://github.com/new) ← الاسم: `class-hub` (أو أي اسم) ← **Public** ← Create.

### 2) ارفع الملفات
**Add file → Upload files** ← اسحب `index.html` و `data.js` و `README.md` (**بدون** `admin.html`) ← Commit.

### 3) فعّل الموقع
**Settings → Pages** ← Source: `Deploy from a branch` ← Branch: `main` / `/(root)` ← **Save**

الرابط: `https://USERNAME.github.io/class-hub/`

### 4) أنشئ Token
[github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)
- Repository access ← **Only select repositories** ← مستودع الموقع فقط
- Permissions → Repository permissions → **Contents: Read and write** (لا شيء آخر)
- Genereate token → انسخه

### 5) اربط اللوحة
افتح `admin.html` بالنقر المزدوج ← تبويب **🚀 النشر والتحديث** ← املأ:
اسم المستخدم · المستودع · الفرع `main` · المسار `data.js` · التوكن ← **⬇️ جلب البيانات الحالية**.

| ما تعدّله | أين في اللوحة | يظهر للطلاب بعد النشر |
|---|---|---|

⚠️ **تنبيه مهم عند العمل من جهاز آخر**: تعديلاتك تُحفظ في متصفح الجهاز الذي تعمل عليه. إن انتقلت إلى لابتوب آخر أو متصفح آخر، اضغط **⬇️ جلب البيانات الحالية** أولاً قبل أي تعديل، وإلا نشرت نسخة قديمة فوق الأحدث.

## 💾 الحفظ والنشر (مهم)

في أسفل لوحة المعلم **شريط دائم** يخبرك بحالة عملك:

| الحالة | المعنى |
|---|---|
| 🟢 **«كل التعديلات منشورة ومطابقة لموقع الطلاب»** | لا يوجد شيء جديد |
| 🟠 **«تعديلاتك محفوظة على جهازك — اضغط النشر»** | التعديل محفوظ **محلياً فقط** ولم يره الطلاب بعد |

القاعدة بسيطة: **لا يوجد زر «حفظ»**، لأن كل ما تكتبه يُحفظ تلقائياً في متصفحك فور الكتابة. أما إظهاره للطلاب فيحتاج زراً واحداً: **🚀 النشر إلى GitHub** (وهو موجود في الشريط السفلي نفسه وفي آخر تبويب «النشر والتحديث»).

> لتغيير اسمك: تبويب **⚙️ عام** ← عدّل «اسم المعلم» (وعدّل «العنوان الكبير» إن أردت) ← اضغط 🚀 النشر إلى GitHub. زر **🔗 اجعل العنوان = «بوابة» + اسم المعلم** يضبط العنوان الكبير تلقائياً.

## 📄 بطاقة ملف للتحميل (Excel / Word / PDF)

**المشكلة الشائعة:** نسخ رابط صفحة الملف على GitHub (`github.com/USER/REPO/blob/main/file.xlsx`) يفتح **صفحة معاينة** فيها زر Download، لا تنزيلاً مباشراً.

**الحل** — اللوحة تتعامل مع الأمرين تلقائياً:

| ما تلصقه | ما يحدث |
|---|---|
| `github.com/USER/REPO/blob/main/file.xlsx` | يُحوَّل تلقائياً إلى رابط تنزيل مباشر |
| `raw.githubusercontent.com/USER/REPO/main/file.xlsx` | يعمل مباشرة |
| `USER.github.io/REPO/file.xlsx` | يعمل مباشرة |
| أي رابط ينتهي بـ `.xlsx .docx .pdf .zip` … | تُعلَّم البطاقة كـ«تحميل» تلقائياً |

في اللوحة (**الصفوف والبطاقات**) لكل بطاقة:
- ☑️ **«تحميل الملف للجهاز عند الضغط»** — تفعيل/تعطيل وضع التنزيل.
- 🔧 **«حوّل رابط GitHub إلى رابط تحميل مباشر»** — يصلح الرابط فوراً.

على صفحة الطلاب تظهر البطاقة بعلامة **⬇ تحميل الملف**، والضغط عليها ينزّل الملف مباشرة إلى مجلد التنزيلات باسمه الأصلي، دون مغادرة الصفحة.

## 🗑️ حذف لوحة المعلم من GitHub

الهدف: أن تبقى `admin.html` على جهازك فقط، ولا تكون منشورة على الإنترنت.

### الطريقة الأولى — بضغطة واحدة من اللوحة (الأسهل)
تبويب **🚀 النشر والتحديث** ← زر **🗑️ حذف admin.html من المستودع**.
اللوحة تتحقق أولاً: إن كان الملف غير موجود تخبرك «لا حاجة لأي إجراء»، وإن كان موجوداً تحذفه عبر GitHub API ثم تطلب منك التأكد بزر «فحص الحساب والموقع».

### الطريقة الثانية — من موقع GitHub (يدوياً)
1. افتح `github.com/USERNAME/REPO` (مثلاً `mrjfaras101-cell/hub`).
2. اضغط على ملف **`admin.html`** من قائمة الملفات.
3. اضغط أيقونة القلم ✏️ أو ⋯ أعلى الملف ← **Delete file** (أو أيقونة سلة المهملات 🗑️).
4. في صفحة التأكيد اكتب رسالة مثل `حذف لوحة المعلم` ← **Commit changes**.
5. اختصار مباشر لصفحة الحذف:
   `https://github.com/USERNAME/REPO/delete/main/admin.html`

ينتظر GitHub Pages 30–120 ثانية ثم يصبح الرابط 404.

### بعد الحذف
- ✅ نسختك على جهازك **لم تتأثر** — استمر في العمل بها.
- ✅ اضغط **🩺 فحص الحساب والموقع** للتأكد أنه يقول: «لوحة المعلم غير منشورة».
- ⚠️ لا تُعِد رفع `admin.html` مع أي تحديث لاحق. الملفات التي تُرفع للموقع: `index.html` و `data.js` فقط.
- ℹ️ العثور على الملف في «تاريخ المستودع» غير ضار: اللوحة لا تحتوي أي كلمة مرور أو توكن — التوكن محفوظ في متصفح جهازك فقط.

## 🔒 الأمان والخصوصية

- لوحة `admin.html` **غير منشورة** — لا رابط لها على الموقع، ولا يستطيع الطالب الوصول إليها.
- التوكن يُخزَّن في `localStorage` بمتصفحك فقط.
- **لا تُدرج أسماء طلاب أو درجات في `data.js`** — الصفحة العلنية يراها أي شخص.
